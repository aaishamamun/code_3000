# Repository Security Statement

## Intended Users
This repository is intended for myself, my instructor, teaching assistants, and authorized collaborators for educational purposes. The code and documentation are used to complete and evaluate coursework.

## Security Risk Assessment
The overall security risk of this repository is low because it primarily contains educational code and assignments rather than sensitive production data. However, unauthorized access could expose coursework, allow malicious modifications, or compromise accidentally committed sensitive information such as API keys or credentials.

## Security Measures
I have implemented a GitHub branch ruleset to protect the default branch. The ruleset requires changes to go through pull requests, prevents branch deletion and force pushes, and enables code owner review requirements.

These protections help prevent unauthorized or accidental modifications to the repository. I also aim to avoid committing passwords, API keys, credentials, or other sensitive information to the repository.
